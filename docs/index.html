MediaWiki extension · v0.8.0

Batch-edit your wiki with AI — preview every change before you save.

Select pages by title list or category, run AI operations (wikilinks, spellcheck, formatting, style, or custom instructions), review wiki-style diffs, approve, and save through MediaWiki's normal edit pipeline.

Features

Built for production wikis: server-side LLM calls, permissions, rate limits, and audit logging.

Batch page selection

Paste titles or load from a category with an optional prefix filter. Validation shows editable pages and skips problems early.

Five AI operations

Wikilinks, spellcheck, formatting, writing style, and a custom mode driven entirely by your instructions.

Diff preview

Each proposed edit is rendered with MediaWiki's DifferenceEngine before anything is saved.

Approve before save

Approve per page or in bulk. Saves use your edit summary and the aibatcheditor change tag.

Configurable profiles

Conservative, balanced, and aggressive presets per operation via $wgAIBatchEditorOperationProfiles.

Production hardening

Rate limits, page size caps, parallel processing, bulk retry for failures, and Monolog audit channel.

Workflow

  1. Validate pages Title list or category (+ optional prefix). Oversized or non-editable pages are flagged.
  2. Choose operation & profile Pick the AI task and aggressiveness. Add batch-wide instructions separate from the wiki edit summary.
  3. Draft AI runs in parallel (configurable concurrency). Unchanged pages show as omitted.
  4. Review diffs Override instructions per page, re-draft individually, or retry all failed pages at once.
  5. Approve & save Approved edits go through PageUpdater with your summary and full attribution.

Installation

Requires MediaWiki 1.43+ and a Grok-compatible chat completions endpoint (xAI by default).

git clone https://github.com/YOUR_USERNAME/AIBatchEditor.git extensions/AIBatchEditor

Add to LocalSettings.php:

wfLoadExtension( 'AIBatchEditor' );

$wgAIBatchEditorApiUrl = 'https://api.x.ai/v1/chat/completions';
$wgAIBatchEditorApiKey = getenv( 'XAI_API_KEY' ) ?: '';
$wgAIBatchEditorModel = 'grok-4.3';
$wgAIBatchEditorDefaultProfile = 'balanced';
$wgAIBatchEditorMaxBatch = 50;
$wgAIBatchEditorMaxPageSize = 51200;
$wgAIBatchEditorRateLimitPerHour = 100;
$wgAIBatchEditorConcurrency = 3;

Store the API key in the environment (e.g. .env for Docker), never in git. Then open Special:AIBatchEditor.

Users need the aibatchedit right (granted to sysop by default).
